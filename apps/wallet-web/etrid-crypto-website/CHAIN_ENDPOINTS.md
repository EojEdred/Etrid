## Connection Examples

### JavaScript/TypeScript (Polkadot.js)

```typescript
import { ApiPromise, WsProvider } from '@polkadot/api';

// Connect to Primearc Core
const relayProvider = new WsProvider('wss://ws.etrid.org/primearc');
const relayApi = await ApiPromise.create({ provider: relayProvider });

// Connect to BTC-PBC
const btcProvider = new WsProvider('wss://rpc.etrid.org:9946');
const btcApi = await ApiPromise.create({ provider: btcProvider });

// Get balance
const account = await btcApi.query.system.account('5GrwvaEF...');
console.log(account.data.free.toString());
```

### cURL (HTTP)

```bash
# Get chain info from BTC-PBC
curl -X POST \
  https://rpc.etrid.org:9946 \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "system_chain",
    "params": [],
    "id": 1
  }'
```

## Health Check Endpoints

### Check Node Status
```bash
# Replace {port} with chain port (9945-9956)
wscat -c wss://rpc.etrid.org:{port}

# Then send:
{"jsonrpc":"2.0","method":"system_health","params":[],"id":1}
```

### Expected Response
```json
{
  "jsonrpc": "2.0",
  "result": {
    "isSyncing": false,
    "peers": 12,
    "shouldHavePeers": true
  },
  "id": 1
}
```

## Firewall Configuration

If hosting nodes, open these ports:

```
TCP/UDP Inbound:
  9944 (Primearc Core)
  9945-9956 (PBC Chains)
  30333 (P2P for all chains)
```

### iptables Example
```bash
# Allow Primearc Core
sudo iptables -A INPUT -p tcp --dport 9944 -j ACCEPT

# Allow all PBC ports
sudo iptables -A INPUT -p tcp --dport 9945:9956 -j ACCEPT

# Allow P2P
sudo iptables -A INPUT -p tcp --dport 30333 -j ACCEPT
```

## Troubleshooting

### Connection Timeouts
```bash
# Test connectivity
nc -zv rpc.etrid.org 9946

# Expected output:
# Connection to rpc.etrid.org 9946 port [tcp/*] succeeded!
```

### SSL/TLS Errors
- Ensure using `wss://` for production
- Use `ws://` only for local development
- Check firewall allows port access

### Node Behind?
```bash
# Check if node is syncing
wscat -c wss://rpc.etrid.org:9946
{"jsonrpc":"2.0","method":"system_syncState","params":[],"id":1}
```

## Rate Limits

### Public RPC
- No strict rate limits currently
- Please be respectful with requests
- Consider running your own node for heavy usage

### Recommended Limits
- Max 100 requests/second per IP
- Max 10 concurrent WebSocket connections
- Use HTTP for one-off queries
- Use WebSocket for subscriptions
