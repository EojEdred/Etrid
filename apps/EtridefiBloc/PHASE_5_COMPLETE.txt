📝 SUPPORTED RPC METHODS

TRANSACTION METHODS:
  • eth_sendTransaction          Sign and broadcast transactions
  • eth_signTransaction          Sign without sending

SIGNATURE METHODS:
  • personal_sign                EIP-191 personal messages
  • eth_sign                     Raw message signing (dangerous)
  • eth_signTypedData            EIP-712 v1
  • eth_signTypedData_v1         EIP-712 v1
  • eth_signTypedData_v3         EIP-712 v3
  • eth_signTypedData_v4         EIP-712 v4 (latest)

CHAIN MANAGEMENT:
  • wallet_switchEthereumChain   Switch active network
  • wallet_addEthereumChain      Add custom networks
  • wallet_watchAsset            Add tokens to wallet

INFORMATION:
  • eth_accounts                 Get connected accounts
  • eth_chainId                  Get current chain ID

   → Recommended: CryptoSwift or web3.swift

   → 'wc' scheme for WalletConnect
   → 'etridwallet' scheme for app

   → Initialize WalletConnectService

⚠️ CRITICAL NOTES

PLACEHOLDER IMPLEMENTATIONS:

  The following files use PLACEHOLDER implementations and MUST be replaced
  with production crypto libraries before deployment:

  1. Core/WalletConnect/Secp256k1.swift
     → Replace with: CryptoSwift, web3.swift, or libsecp256k1
     → Required for: Message signing, signature verification

  2. Core/WalletConnect/Keccak256.swift
     → Replace with: CryptoSwift, web3.swift, or tiny-keccak
     → Required for: Ethereum-compatible hashing

  WITHOUT these integrations, cryptographic operations will NOT work!

RECOMMENDED SOLUTION:
  
  Use CryptoSwift (provides both Keccak-256 and secp256k1):
  
  Package.swift:
  .package(url: "https://github.com/krzyzanowskim/CryptoSwift.git", 
           from: "1.8.0")
  
  Implementation:
  import CryptoSwift
  
  // Keccak-256
  let hash = data.sha3(.keccak256)
  
  // Secp256k1 signing
  // (See CryptoSwift documentation)
