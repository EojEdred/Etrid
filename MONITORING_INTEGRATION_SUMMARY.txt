4. GOVERNANCE ARCHITECTURE

   How Voting Works:

   User Wallet
      │
      │ 1. Connect Polkadot.js wallet
      ↓
   Wallet Governance Page (localhost:3000/governance)
      │
      │ 2. Display proposals from Snapshot
      ↓
   Snapshot UI (localhost:8082)
      │
      │ 3. User clicks "Vote"
      │ 4. Signs vote with wallet (NO GAS FEE!)
      ↓
   Snapshot Hub (hub.snapshot.org)
      │
      │ 5. Validate signature
      │ 6. Calculate vote weight from on-chain stake
      │ 7. Update live results
      ↓
   PrimeArc Core Chain (on-chain pallets)
      │
      │ 8. If proposal passes:
      │ 9. Directors execute via governance pallet
      ↓
   Changes Take Effect

   Key Governance Components:

   • Standard Proposals:
     - Simple majority (>50%)
     - No minimum participation
     - Examples: Protocol upgrades, treasury spends

   • Consensus Day Proposals:
     - Occurs annually (January 1)
     - Supermajority required (60-100%)
     - Minimum participation (20-100%)
     - Examples: Director elections, constitution changes

   • 9-Director System:
     - 9 elected directors
     - 6/9 quorum for emergency actions
     - Annual elections on Consensus Day
     - 24-hour timelock on emergency actions
