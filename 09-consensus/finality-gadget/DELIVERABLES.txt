TECHNICAL SPECIFICATIONS
================================================================================

Language: Rust (Edition 2021)
Dependencies:
  • codec (SCALE encoding)
  • sp_core (Substrate primitives)
  • tokio (async runtime)
  • hex (logging)
  • tracing (structured logging)

Architecture:
  • Async/await throughout
  • RwLock for thread safety
  • Unbounded channels for slashing
  • HashMap for vote tracking
  • AtomicU64 for view counter

Memory Model:
  • Bounded by max_views_retained (default: 1000)
  • Automatic cleanup every 60 seconds
  • O(validators × views) space complexity
  • ~1MB for typical deployment (100 validators)

Threading Model:
  • Thread-safe with RwLock
  • Multiple concurrent readers
  • Exclusive writer access
  • Lock-free current_view updates
