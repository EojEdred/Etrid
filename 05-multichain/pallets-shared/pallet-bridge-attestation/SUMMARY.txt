--------

verification for cross-chain bridge messages. Can be used by ANY PBC 
(Partition Burst Chain) in the Etrid ecosystem.

KEY FEATURES:
-------------
1. Generic & Reusable - Works with any PBC
2. Multi-Signature Support - ECDSA (EVM) and SR25519 (Substrate)
3. Configurable Chain ID - Each PBC sets its own ID
4. M-of-N Thresholds - Byzantine fault tolerant
5. Replay Protection - Nonce-based security
6. Emergency Pause - Governance can halt operations
7. Rich Public API - Easy integration for other pallets
8. Well Documented - 1,400+ lines of documentation
9. Fully Tested - Comprehensive test suite
10. Production Ready - Follows Substrate best practices

SUPPORTED SIGNATURE TYPES:
--------------------------
• ECDSA (33-byte compressed)   - For EVM bridges (Ethereum, BSC, etc.)
• ECDSA (65-byte uncompressed) - For EVM bridges (alternate format)
• SR25519 (32-byte)            - For Substrate bridges (Polkadot, etc.)

EXTRINSICS:
-----------
Governance (require root):
  • register_attester(public_key)
  • disable_attester(attester_id)
  • enable_attester(attester_id)
  • remove_attester(attester_id)
  • configure_threshold(domain_id, min_sigs, total)
  • update_threshold(new_threshold)
  • pause_attestation()
  • unpause_attestation()

Public (permissionless):
  • submit_signature(attester_id, hash, sig, source, dest, nonce)
  • verify_attestation(message, hash)

STORAGE ITEMS:
--------------
  • Attesters - Attester registry (id → info)
  • AttesterByPubkey - Reverse lookup (pubkey → id)
  • NextAttesterId - Auto-increment counter
  • ActiveAttesterCount - Count of active attesters
  • Attestations - Message attestations (hash → attestation)
  • ThresholdConfigs - Per-domain thresholds
  • GlobalThreshold - Global threshold config
  • IsPaused - Emergency pause flag
  • TotalAttestations - Statistics counter
  • AttestationNonce - Nonce generator
  • UsedNonces - Replay protection

HELPER FUNCTIONS (for other pallets):
--------------------------------------
  • hash_message(message) -> H256
  • get_chain_id() -> u32
  • get_and_increment_nonce() -> u64
  • get_threshold_for_domain(domain) -> u32
  • verify_attestation_for_message(message, hash) -> Result
  • is_attestation_valid(hash) -> bool
  • get_active_attesters() -> Vec<u32>

USAGE IN OTHER PALLETS:
------------------------
use pallet_bridge_attestation as BridgeAttestation;

// Verify attestation before processing message
